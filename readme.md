## environment simulation

Semantic models of an autonomous delivery robot operating during a heavy-rain flash flood.

- [`semantic-model.md`](semantic-model.md) — Westfield Century City (Los Angeles):
  a multi-level shopping center with below-grade parking and mall management.
- [`semantic-model-retail-street.md`](semantic-model-retail-street.md) — a generic
  retail street (Maple Street) with sidewalks, crossings, and storm drains.

Each model defines entities, relationships, rules (constraints), actions, and an
example test scenario.
